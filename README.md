# ⚔️ WowLK 3.3.5a Launcher by ApodeZ

Кастомный open-source лаунчер и конфигуратор для клиента **World of Warcraft: Wrath of the Lich King (3.3.5a)**, разработанный на C# (Windows Forms).

---

## 🌟 Основные возможности

* **Гибридный рендеринг:** Поддержка работы `Reshade + Vulkan` через динамическое внедрение слоев окружения (`VK_LAYER_PATH` и `VK_INSTANCE_LAYERS`).
* **Управление HD-патчами:** Включение/выключение кастомных модификаций моделей, текстур мира, заклинаний и интерфейса без ручного переименования файлов.
* **Автоматическая очистка:** Опциональная очистка папки `Cache` перед запуском игры для предотвращения графических багов.
* **Кастомный UI:** Анимированный интерфейс с эффектом параллакса при движении мыши, динамическим снегопадом и музыкальным сопровождением.

---

## 🛠️ Технологии

* **Язык:** C# / .NET Framework
* **GUI:** Windows Forms (Win32 API, GDI+)
* **Интеграция рендера:** DXVK (Vulkan), ReShade
