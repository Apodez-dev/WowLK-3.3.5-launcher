# ⚔️ WowLK 3.3.5a Launcher by ApodeZ

Кастомный open-source лаунчер и графический конфигуратор для клиента **World of Warcraft: Wrath of the Lich King (3.3.5a)**, разработанный на C# (Windows Forms). Проект создан для удобного управления гибридным рендерингом, HD-модификациями и очисткой кэша в один клик.

## 🌟 Основные возможности

* **Гибридный рендеринг:** Поддержка работы `Reshade + Vulkan` (DXVK) через динамическое внедрение системных слоев окружения (`VK_LAYER_PATH` и `VK_INSTANCE_LAYERS`).
* **Управление HD-патчами:** Удобное включение и отключение модификаций моделей, текстур мира, заклинаний и интерфейса (`patch-ruRU-*.mpq`) без необходимости вручную переименовывать файлы.
* **Автоматическая очистка:** Опциональная очистка папки `Cache` перед запуском игры для предотвращения графических багов и рассинхронизации кэша.
* **Кастомный UI:** Атмосферный интерфейс в стиле игры, анимированный снегопад, динамический параллакс-эффект при движении мыши и встроенное музыкальное сопровождение.
* **Безопасность конфигураций:** Сохранение пользовательских настроек в локальный файл `launcher_config.txt`.

## 🚀 Быстрый старт и установка

1. Перейдите в раздел **[Releases](../../releases)** справа и скачайте последний архив с лаунчером (`.zip`).
2. Распакуйте содержимое архива **в корневую папку с установленной игрой World of Warcraft 3.3.5a** (туда, где находится оригинальный файл `Wow.exe`).
3. Запустите исполняемый файл **`WOW_launcher.exe`**.
4. Выберите готовый пресет в главном меню или перейдите в «Конструктор сборки» для тонкой настройки графики и модов.
